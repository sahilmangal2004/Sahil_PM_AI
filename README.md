# Sahil AI Interactive

REDESIGN THE PORTFOLIO EXPERIENCE — GEN-Z AI-NATIVE INTERACTIVE STYLE

I want to transform my existing Sahil Mangal Product Management portfolio

into a visually striking, modern, Gen-Z tech/AI-native portfolio.

IMPORTANT:

Do NOT completely rebuild the existing content or remove sections.

Keep all existing:

- About

- Experience

- Projects

- Skills

- Testimonials

- Leadership

- AI assistant

- Contact

- Company names

- Existing portfolio information

Focus primarily on improving the VISUAL EXPERIENCE, ANIMATIONS,

INTERACTIONS and MICRO-INTERACTIONS.

The website should feel like:

"An ambitious Gen-Z product builder who understands AI, data,

technology and product — not a generic student portfolio."

DESIGN DIRECTION

Create a premium futuristic interface inspired by modern AI startups,

creative developer portfolios and high-end product websites.

Visual personality:

- Minimal but expressive

- Premium

- Slightly experimental

- AI-native

- Interactive

- Gen-Z

- Tech-forward

- Confident

- Not childish

- Not overly corporate

Avoid:

- Generic Bootstrap-style cards

- Excessive gradients

- Excessive glassmorphism

- Huge amounts of text

- Stock illustrations

- Generic AI robot graphics

- Excessive neon

- Slow/heavy animations

- Cringe motivational quotes

- "Welcome to my portfolio" type intros

--------------------------------------------------

1. HERO SECTION

--------------------------------------------------

Make the hero section immediately impressive.

Use a large typography-driven introduction:

"Hi, I'm Sahil."

Then:

"Product-minded builder working at the intersection of

Product × Data × AI."

Add a subtle animated text effect that cycles through:

PRODUCT

DATA

AI

AUTOMATION

EXPERIMENTATION

Use smooth word transitions rather than a cheesy typewriter effect.

Add a small status indicator:

● Currently building with AI

Animate the dot with a subtle pulse.

Add two primary CTAs:

"Explore my work"

"Talk to Sahil AI"

CTA hover:

- slight magnetic movement

- subtle scale

- smooth glow

- cursor interaction

--------------------------------------------------

2. INTERACTIVE CURSOR

--------------------------------------------------

Create a custom modern cursor experience.

Normal cursor:

small circular dot.

When hovering over:

- buttons → cursor expands

- project cards → cursor says "VIEW"

- AI assistant → cursor says "ASK"

- external links → cursor says "OPEN"

Keep it subtle and performant.

Disable custom cursor automatically on mobile.

--------------------------------------------------

3. SCROLL EXPERIENCE

--------------------------------------------------

Make scrolling feel intentional.

Use subtle scroll-triggered animations.

Elements should:

- fade in

- move upward slightly

- scale from 0.97 → 1

- stagger naturally

Do NOT animate every element aggressively.

Use animation hierarchy.

Major sections should feel like scenes.

Example:

Hero

↓

Experience

↓

Impact

↓

Projects

↓

Testimonials

↓

AI

↓

Contact

Each transition should feel smooth and cinematic.

--------------------------------------------------

4. EXPERIENCE SECTION

--------------------------------------------------

Instead of a boring vertical resume timeline,

create an interactive experience timeline.

Each company should appear as a large interactive row/card.

Companies:

GoEddie.ai

QuikyGo

Forethought India

On hover:

- company name becomes more prominent

- dates slide/fade in

- role appears

- subtle background movement

Clicking a company expands the experience.

Show:

Role

Duration

What I worked on

Impact

Key metrics

Animate the expansion smoothly.

Do NOT make the cards huge.

--------------------------------------------------

5. COMPANY BRANDING

--------------------------------------------------

Make company names visually prominent.

Use subtle company-specific visual identities,

but do not use random fake logos.

If actual logos are available in the existing project,

use them.

Otherwise use elegant text-based company marks.

Hover animation:

company name

→ slight horizontal movement

→ arrow appears

→ subtle underline animation

--------------------------------------------------

6. IMPACT / METRICS SECTION

--------------------------------------------------

Create a visually strong "Impact" section.

Large animated numbers:

90%

Manual effort reduction

30%

Fewer vendor data inconsistencies

1,500+

Stores processed

95%+

Documented data accuracy

100+

Active testers

Animate numbers counting up when they enter the viewport.

Use oversized typography.

Make this section feel like a product case-study dashboard,

not a resume.

--------------------------------------------------

7. PROJECTS SECTION

--------------------------------------------------

Make Projects one of the strongest sections.

Use large interactive project cards.

Projects:

Shopify Scraper

Streaming Analytics

Other existing projects from the portfolio

Each card should have:

Project name

Short description

Tech stack

Problem

What I built

Result

Hover interaction:

- card slightly tilts toward cursor

- image/background moves subtly

- arrow appears

- border/glow reacts to cursor

- project number shifts slightly

Do NOT overdo the 3D effect.

Use perspective only around 2–4 degrees.

--------------------------------------------------

8. PROJECT CARD "MAGNETIC" EFFECT

--------------------------------------------------

When the mouse moves inside a project card,

create a subtle radial highlight following the cursor.

Example:

cursor position

↓

soft spotlight

↓

card reacts

The effect should be smooth and extremely subtle.

Avoid rainbow gradients.

--------------------------------------------------

Create an interactive skill cloud / grid.

Categories:

--------------------------------------------------

10. TESTIMONIALS

--------------------------------------------------

Make testimonials feel like social proof,

not LinkedIn recommendations copied into boxes.

Use a horizontal interactive testimonial carousel.

Testimonials:

CEO, QuikyGo

CTO, QuikyGo

Cards should have:

quote

person

company

Add subtle:

- card entrance animation

- horizontal drag

- arrow navigation

- hover elevation

Do NOT use fake profile photos.

If no real photo is available,

use elegant initials/avatar treatment.

--------------------------------------------------

11. AI ASSISTANT — MOST IMPORTANT

--------------------------------------------------

Make the AI assistant feel like an actual AI product.

Do NOT make it look like a basic chat textbox.

Section heading:

"Sahil AI"

Subheading:

"Ask me anything."

The assistant should clearly be a GENERAL PURPOSE AI,

not just a portfolio FAQ bot.

Example suggested prompts:

"Explain SQL joins"

"Help me prepare for a PM interview"

"What is product-market fit?"

"Tell me about Sahil"

"What did Sahil build at QuikyGo?"

"How would you improve QuikyGo?"

Use animated suggestion chips.

When the user opens the AI:

Create a smooth expanding interface.

Loading animation:

three intelligent pulsing dots.

Response animation:

stream text naturally rather than showing everything instantly.

Add subtle message entrance animations.

The AI interface should feel inspired by modern AI products,

but DO NOT clone ChatGPT's UI.

--------------------------------------------------

12. AI VISUAL EFFECT

--------------------------------------------------

Add a subtle animated "AI orb" or abstract intelligence visualization

near the AI section.

The orb should:

- slowly rotate

- respond to mouse movement

- pulse while AI is thinking

- become slightly brighter while generating

- return to idle state afterward

Keep it elegant.

Do NOT create a humanoid robot.

--------------------------------------------------

13. NAVIGATION

--------------------------------------------------

Create a floating navigation bar.

When scrolling:

Navigation becomes slightly smaller.

Use:

Sahil

Work

Projects

Testimonials

AI

Contact

Add a subtle backdrop blur.

On hover:

underline smoothly grows from left → right.

--------------------------------------------------

14. SCROLL PROGRESS

--------------------------------------------------

Add a very subtle scroll progress indicator.

It should show how far the visitor has travelled through the portfolio.

Keep it minimal.

--------------------------------------------------

15. PAGE TRANSITIONS

--------------------------------------------------

Use smooth transitions between sections.

Do not use flashy page transitions.

Prefer:

fade

slide

scale

Duration:

approximately 400–700ms.

Use easing curves that feel natural.

--------------------------------------------------

16. MICRO-INTERACTIONS

--------------------------------------------------

Add polished micro-interactions everywhere appropriate.

Examples:

Buttons:

hover → scale 1.03

Cards:

hover → translateY(-4px)

Links:

animated underline

Arrows:

move slightly right on hover

Numbers:

count-up animation

Images:

subtle parallax

Sections:

staggered entrance

AI:

thinking animation

Testimonials:

drag interaction

Projects:

cursor spotlight

--------------------------------------------------

17. BACKGROUND

--------------------------------------------------

Create a subtle dynamic background.

Possible effects:

- very subtle grain

- extremely slow moving gradient mesh

- soft grid

- tiny particles

- mouse-reactive light

Use ONE or TWO of these.

Do not combine everything.

The background should remain readable and professional.

--------------------------------------------------

18. TYPOGRAPHY

--------------------------------------------------

Use a modern typography system.

Hero:

very large bold typography.

Body:

clean readable typography.

Metrics:

oversized numbers.

Use strong contrast between:

headline

supporting text

metadata

Avoid using 5+ fonts.

Maximum:

2 font families.

--------------------------------------------------

19. MOBILE EXPERIENCE

--------------------------------------------------

The animations must remain excellent on mobile.

On mobile:

- disable custom cursor

- reduce parallax

- reduce heavy animations

- preserve card interactions

- make AI interface full-width

- make navigation compact

- keep touch targets large

Performance is extremely important.

--------------------------------------------------

20. PERFORMANCE

--------------------------------------------------

Do NOT sacrifice performance for visual effects.

Use:

CSS transforms

opacity

requestAnimationFrame where necessary

IntersectionObserver

GPU-friendly animations

Avoid:

constant expensive re-renders

large canvas animations

huge video backgrounds

unnecessary 3D libraries

heavy particle systems

Respect:

prefers-reduced-motion

If the user has reduced motion enabled,

disable non-essential animations.

--------------------------------------------------

21. OVERALL FEEL

--------------------------------------------------

The final website should feel like:

"If a Gen-Z product manager who understands AI,

data and technology designed his own digital product."

It should feel:

interactive

alive

premium

confident

modern

AI-native

But NOT:

corporate

template-like

childish

overly neon

over-animated

generic

Every animation should have a purpose.

The website should look impressive within the first

5 seconds without requiring the visitor to scroll.

IMPORTANT:

Do not remove existing content.

Do not invent new experience.

Do not invent metrics.

Do not invent testimonials.

Do not invent companies.

Improve the EXPERIENCE of presenting the existing portfolio.
